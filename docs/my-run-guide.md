\# Run Guide



\## Prerequisites

\- Python 3 installed (`python3 --version`으로 확인)

\- 이 repository를 clone한 상태



\## Run

python3 run.py demo



\## What the demo does

고정 날짜(2026-09-01)를 기준으로 도서관 대출 시스템을 시연한다. 학생과 교수의 대출 한도를 출력하고, 책 검색, 대출(Alex가 Git Essentials를 대출, 반납 기한 2026-09-15), 반납을 차례로 처리해 연체료(0)와 남은 대출 수(0)를 보여준다.
